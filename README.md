# Sourav Das — Personal Academic Website

A responsive, static personal website built from the current CV details.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build tools, framework, or dependencies are required.

## Publish with GitHub Pages
1. Create a repository named `dassourav0151.github.io` on GitHub (or use another repository for a project site).
2. Upload `index.html` to the repository root and commit the changes.
3. For a user site, open **Settings → Pages**, select the `main` branch and `/ (root)`, then save.
4. After GitHub Pages publishes the site, it will be available at `https://dassourav0151.github.io/`.

## Before publishing
- Review all biographical details, publication statuses, and links.
- Add a CV PDF if you want a downloadable CV link.
- You can replace the initials monogram in the hero section with a portrait if preferred.
- The email and social links are public because this is a public-facing academic website.

## Files
- `index.html` — complete website, including styles and responsive navigation.
- `profile.jpg` — profile photograph used in the hero section; keep this file beside `index.html`.
